
# DYAU Website — Project Rules

## Project Identity
Brand: DYAU
Brand monogram: DY
Primary logo: Approved black DY wordmark
Accent: #FF570A

## Mandatory Instructions
1. Read DYAU_WEBSITE_AGENT_INSTRUCTIONS.md before implementation.
2. Use TypeScript and React.
3. Use pnpm exclusively.
4. Preserve original source PDF content.
5. Never invent statistics or testimonials.
6. Use reusable, modular components.
7. Keep content separate from UI components.
8. Follow the approved design system.
9. Use Motion for React as the primary animation library.
10. Use GSAP only for specialist animations.
11. Keep all routes and interactions functional.
12. Maintain responsive design.
13. Test before declaring a feature complete.

## Code Quality
- Avoid unnecessarily large components.
- Use descriptive filenames.
- Avoid duplicated code.
- Keep API logic separate.
- Use reusable hooks.
- Document complex animation logic.
- Preserve accessibility.
- Do not commit secrets.

## Development Workflow
Audit → Plan → Design → Implement → Test → Review.

Never change the approved brand direction without explicit approval.
